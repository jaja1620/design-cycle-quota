# 《全国建筑设计周期定额（2016版）》深度解读与"建筑设计周期定额计算"软件设计大纲

> 编制依据：《全国建筑设计周期定额（2016版）》（住房城乡建设部组织修编）
> 用途：作为"建筑设计周期定额计算"软件（输入建筑性质、规模及其它参数，按定额规则生成 Word 版周期定额计算报告）的设计基础。
> 规则决策状态：15 项未明确问题已由用户逐条定稿（2026-11-02），决策已回填各章节并完整固化于第九节，作为软件规则库与计算引擎的**最终依据**。

---

## 一、文档定位与适用范围（软件的业务前提）

### 1.1 定额的法定用途
- 建设单位与设计单位签订建设工程设计合同、确定**合理设计周期**的依据。
- 编制方案设计招标文件时作为参照依据。
- 建设单位和设计单位**不得任意压缩设计周期**。

### 1.2 适用对象
- 以**单项工程**为单位，分别套用。
- 类似的工程可参照套用；无法套用时，另行商定周期。

### 1.3 设计阶段划分（核心结构）
| 模式 | 阶段构成 | 适用对象 |
|---|---|---|
| 三阶段 | 方案设计 + 初步设计 + 施工图设计 | 常规工程 |
| 两阶段 | 方案设计 + 施工图设计（直接进入） | 功能单一、技术要求简单的"简单和一般"类项目（经商定） |

- **两阶段规则**：由方案设计直接进入施工图设计的项目，其**初步设计周期并入施工图设计周期**之内。

### 1.4 时间单位定义
- 1 日历月 = 4 个日历周（近似）= 28 天。
- 0.25 个月 = 1 个日历周 = 7 天；每年 12 个日历月。

## 二、计算要素关系总览（软件的核心数据流）

```
建筑类别（9大类）
   └─→ 建筑子类型（39个定额编号）
        └─→ 定额表（规模档位 × 方案/初步/施工图/合计 周期）
             └─→ 规模匹配（档位命中 / 插入法 / 低于起档 / 高于最高档等比推算 / 未覆盖区间等比推算）
                  └─→ 基础周期（方案 + 初步 + 施工图 = 合计）
                       └─→ 设计模式调整（两阶段合并初步周期）
                            └─→ 修正调整规则（14条，默认叠加、可分组统筹）
                                 └─→ 最终设计周期（日历月）
```

**要素关系结论**：
1. **建筑类型** → 唯一确定一张定额表（决定档位规模序列与各阶段周期值）。
2. **建筑规模（面积）** → 在定额表内确定具体取值（决定周期数值）；规模指**总建筑面积（含地下和地上）**。
3. **设计模式** → 决定阶段数量与合并方式（决定合计口径）。
4. **工程状态与委托方式** → 触发 14 条调整规则（决定最终周期）。
5. **合计周期 = 方案 + 初步 + 施工图**（表内合计列为校验基准，均等于三阶段之和）。

## 四、基础周期取值规则（规模匹配引擎）

### 4.1 规模口径（Q12 决策）
- **规模指总建筑面积，包含地下和地上部分**。
- 软件输入校验与报告文案均按此口径提示。

### 4.2 规模档位判定
输入规模 S（平方米）与定额表规模序列 {S1, S2, ..., S8} 比较，按以下五种情形取值：

| 情形 | 判定条件 | 取值规则 |
|---|---|---|
| 档位命中 | S = Si（表内某档） | 直接取该档方案/初步/施工图周期 |
| 两档之间 | Si < S < Si+1 | **插入法（线性插值）** |
| 低于起档 | S < S1 | 采用起档（最低档）周期 |
| 高于最高档 | S > S8 | **等比推算（Q1 决策）**：T = T最高档 × S / S最高档；报告必须标注"此值在定额标准中未明确计算方法，按默认定义方式推算" |
| 未覆盖区间 | 定额表未涵盖（如疗养/养老院 200 床以下） | **向下等比推算（Q13 决策）**：按疗养类 10000㎡ 规模档周期为基准等比推算；报告必须标注"定额标准未涵盖，由此规则推算" |

- **插入法公式**（对每个阶段分别计算）：
  `T = T1 + (T2 − T1) × (S − S1) / (S2 − S1)`
  其中 T1、T2 为相邻两档周期，S1、S2 为相邻两档规模。

### 4.3 精度与进位规则（Q11 决策）
- 默认**四舍五入**，保留 **2 位**小数。
- GUI 提供进位规则与保留位数自定义选项（用户可改）。

### 4.4 阶段周期与合计
- 三阶段模式合计 = 方案设计 + 初步设计 + 施工图设计。
- 两阶段模式：初步设计周期并入施工图设计周期（见 5.2）。

## 五、设计模式与阶段周期计算

### 5.1 三阶段模式（默认）
`总周期 = 方案周期 + 初步周期 + 施工图周期`

### 5.2 两阶段模式（简单和一般类，经商定）
- 由方案设计阶段**直接进入**施工图设计阶段。
- **合并口径确认（Q5 决策）**：`施工图阶段周期 = 初步设计表值 + 施工图设计表值`；方案阶段照常。
- **判定方式（Q14 决策）**：由**用户自行判断**是否合并；GUI 面板提供"是否合并初步设计和施工图阶段"选项，选项旁提示："按《全国建筑设计周期定额（2016版）》第一章总说明第（二）条规定，技术要求简单的'简单和一般'类项目可合并"。

### 5.3 阶段范围定义（报告需向用户说明）
- 方案设计：按设计任务书与基础资料进行方案设计（直接委托做正式方案，投标中标做实施方案）。
- 初步设计：按方案书面批复进行，完成初步设计经济，完成会审修改，达到进入施工图设计深度。
- 施工图设计：按初步设计书面批复进行，含室外总体设计、管线综合设计，达到设计深度并通过施工图审查。

## 六、周期范围界定（计算范围的前置条件）

### 6.1 计入范围（起点—终点）
自**设计条件具备**开始正式实施方案设计、初步设计 → 到**全部施工图设计完成、通过施工图审查并完成改图、向建设单位提交设计文件**。

### 6.2 不计入范围（10 类，软件报告需提示不在计算内）
1. 设计前期工作
2. 设计方案投标及方案多轮概念性筛选
3. 设计前赴外地现场踏勘、搜集资料和工程调研时间
4. 方案设计、初步设计的审批时间，施工图审查时间
5. 建设单位原因或方案/初步设计批复后发生**方案性重大变更**造成的返工、修改时间
6. 施工图预算
7. 有专门要求的室内外装饰设计
8. 专项设计
9. 绘制竣工图
10. 不属于项目合同涉及范围内的其他技术服务

### 6.3 施工配合
参加施工过程的设计配合、中间验收和竣工验收工作，**总周期不含在《周期定额》中**。

## 七、调整因素与修正规则（14 条，调整引擎，含决策定稿）

> 调整作用于"基础周期（含模式调整后）"之上。**叠加策略（Q15 决策）**：除明确可统筹的规则外，其余规则**全部叠加**；生成报告前弹出"多项规则命中"提示，默认全部叠加；用户可通过"可统筹"选项分组统筹（见 7.2）。

### 7.1 规则表（含决策回填）

| 序号 | 调整因素 | 触发条件 | 修正规则（定稿） | 作用对象 |
|---|---|---|---|---|
| 1a | 复用套图-全部复用 | 全部套用同类工程施工图 | 施工图周期 × 10%；**方案阶段默认照常、初步阶段默认按比例（Q3 决策）** | 施工图阶段 |
| 1b | 复用套图-上部复用 | 上部复用、基础重新设计 | 施工图周期 × 20%；**方案阶段默认照常、初步阶段默认按比例（Q3 决策）** | 施工图阶段 |

### 7.2 叠加与统筹策略（Q15 决策）
- **默认**：所有命中规则全部叠加。
- 生成报告前，弹出"多项规则命中"提示，默认全部叠加。
- 用户可通过"可统筹"选项分组统筹：
  - 统筹选项按**相同数字**形式分组（标同一数字的为同一统筹组，如所有标注"1"的为一组、"2"的为另一组）；
  - 同一统筹组内**以组内最长周期为准**；
  - **最终总周期 = 不可统筹项周期 + 各统筹组周期（每组取最长）之和**。
- 商定项（第 8/13/14 条、第 6 条折减、第 9 条延长）均提供自定义输入入口。

## 八、软件功能与计算流程设计（含 GUI 交互定稿）

### 8.1 输入参数层（GUI 交互）
1. **必填**：建筑类别（9 类下拉）→ 建筑子类型（39 项下拉，联动；酒店类区分 01-5-1/01-5-2）。
2. **必填**：建筑规模（㎡，总建筑面积含地下地上；超过该定额表最大规模时弹出对话框，提供两种方式：①按默认定义方式（等比推算）计算；②用户手动输入周期，手动输入框旁提示等比推算参考值——Q1 决策）。
3. **必填**：设计模式——提供"是否合并初步设计和施工图阶段"选项，旁注提示总说明第（二）条（Q14 决策）。
4. **选填（调整因素）**：
   - 复用套图：选择 1a/1b；方案阶段与初步阶段分别提供"照常 / 取消 / 按比例"选项（方案默认照常、初步默认按比例，可自定义比例值）（Q3 决策）。
   - 改扩建：复杂程度菜单（简单/一般/复杂/特别复杂/自定义 10%～40%）（Q4 决策）。
   - 多单体：可增加、删除单体子项；每项可设"挂起"状态（保留输入但不参与计算）；各单体分别计算后按规则合并/折减，折减可自定义天数或比例，默认不折减（Q6 决策）。
   - 风景区：酒店类勾选"是否位于风景区"，是则总周期 +30%（Q8 决策）。
   - 新技术/特殊要求：按"项"输入（名称、概述、增加时间），可增删、挂起；每项勾选"是否周期可统筹"（Q9 决策）。
