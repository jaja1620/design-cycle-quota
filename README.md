# 建筑设计周期定额计算软件（全国建筑设计周期定额 2016 版）

> 当前版本：**v1.2.0**（参数记忆/一键打开/起止日期推算/计算链等式/节假日明细/多单体总览/输入参数页等 16 项优化）

依据《全国建筑设计周期定额（2016 版）》与已确认的 15 条规则决策，测算建筑设计周期（方案 / 初步 / 施工图阶段），支持多单体、14 条调整规则、节假日、压缩周期、分组统筹等，输出带计算依据标注的 Word 报告与可选 Excel。

## 功能清单

- **数据层**：完整提取定额文档 9 大类 40 个定额子项表的全部档位数据（规模档位与方案 / 初步 / 施工图 / 合计周期，单位日历月），与原文完全一致；其中新增「综合医院（参考 03-2 病房楼）」子项，数据参照 03-2 病房楼（医疗建筑）定额。
- **规模取值**：档位命中直接取值 / 两档间线性插值 / 低于起档取起档 / 高于最高档按规模等比推算（报告标注"定额未明确、默认方式推算"）/ 未涵盖区间按疗养类 10000 ㎡档向下等比推算（标注"定额未涵盖"）/ 用户自定义周期。
- **两阶段模式**：功能单一、技术要求简单的项目，初步设计周期并入施工图设计周期（总说明（二））。
- **14 条调整规则**（默认全部叠加，支持按数字分组统筹、同组取最长）：
  1. 复用套图：施工图 ×10%（全部复用）/ ×20%（上部复用）；方案默认照常、初步默认按比例
  2. 改扩建复杂程度菜单：简单 +10% / 一般 +20% / 复杂 +30% / 特别复杂 +40% / 自定义 10%~40%
  3. 分阶段分别委托：初步、施工图各 +10%
  4. 多单位共同设计：主体 +10%
  5. 五级及以上附建式人防：初步、施工图各 +15%
  6. 多单体子项：默认不折减，可自定义减少天数或比例；单体支持增删 / 挂起（保留数据不参与计算）
  7. 节假日：不增加 / 自动统计（推演至 2039）/ 输入天数 + 覆写天数 + 注释；统计口径：国家法定节假日指除周六、周日以外的其它法定假日，仅累计落在周一至周五的法定节假日日期（不含周六、周日的法定节假日天数）
  8. 风景区建筑 +30%（适用所有酒店类 01-5-1 / 01-5-2）
  9. 新技术按项输入（名称 / 概述 / 增加月数 / 可统筹 / 统筹组号）
  10. 涉外工程默认不增加、可自定义
  11. 返工按返工量增加对应阶段周期
  12. 特殊建筑（古建 / 仿古 / 保护性 / 园林庭院式 / 宗教类）协商输入
  13. 压缩周期：目标总周期或压缩天数，输出占比与风险警告（<50% 警告）
  14. 特殊工程工作量变化协商输入
- **GUI**：莫兰迪色系（米灰 / 灰蓝 / 灰粉 / 沙橙，低饱和度灰调，保持简约高级）；顶栏标题与下拉菜单箭头为深蓝色、文字统一黑色清晰可读；数值输入框启用数字过滤，拒绝异常字符（修复"特殊建筑增加月"输入框初次点击出现 a'a 的问题）；「项目信息 + 单体子项 + 调整因素 + 输出设置」分卡片布局；多单体增删 / 挂起；输出 Word 保存位置自定义、Excel 可选导出。
- **Word 报告**：所有表格带边框；计算依据引用定额原文表格与条款并以浅彩底纹标注；含项目信息、各单体与阶段周期（月 / 天）、分设计阶段单体统计（单体 × 阶段：方案 / 初步 / 施工图 / 阶段小计，月 / 天）、调整明细（规则原文 + 数值）、最终周期（月 / 周 / 天换算，天保留整数）、特殊说明与风险警告、附录（不计入周期的 10 类工作）。
- **Excel（可选）**：项目信息 / 单体周期（合计为公式联动，含天列）/ 调整明细 / 最终周期（周、天公式联动，天保留整数）/ 分阶段统计（单体 × 阶段，月 / 天公式联动），供客户调整后自动刷新。

## 使用说明

1. 双击 `dist/设计周期定额计算.exe` 启动（GUI 弹出时无 CMD 控制台窗口）。
2. 填写项目信息（名称 / 地点 / 设计单位 / 开始时间 / 阶段模式 / 精度 / 多单体折减）。
3. 添加单体子项：选择定额编号（40 个子项，含新增「综合医院（参考 03-2 病房楼）」）、填写规模（㎡）；「200 床以下」仅对 03-4 疗养 / 养老生效；勾选「挂起」保留数据但不参与计算。
4. 勾选 / 填写调整因素；新增技术项与返工项按需添加；分组统筹按 `规则key=组号` 格式填写（如 `9=1,11=1`，同组取最长）。
5. 设置输出：Word 保存位置（自定义）、文件名、是否同时导出 Excel。
6. 点击「开始计算并生成报告」，结果区即时显示各阶段周期（月 / 周 / 天，天保留整数）、分设计阶段单体统计与风险警告，并在指定位置生成 Word / Excel。

## 开发与构建

```bash
# 安装依赖
pip install -r requirements.txt

# 源码运行
python src/app.py

# 打包 exe（隐藏 CMD 控制台窗口）
pyinstaller --noconfirm --onefile --windowed --name 设计周期定额计算_1.2.0 ^
  --paths src src/app.py
# 或使用项目内 build_exe.bat
```

打包产物位于 `dist/设计周期定额计算_1.2.0.exe`，`--windowed` 使 GUI 弹出时无控制台窗口（等价 pythonw 方式启动）。

## 时间单位

- 1 日历月 = 4 日历周 = 28 天；0.25 月 = 1 周 = 7 天。
- 报告、GUI 与 Excel 均给出 月 / 周 / 天 三套换算；天按 1 月 = 28 天换算并**保留整数**（如 1.5 月 = 42 天）。
